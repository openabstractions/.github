# Layer catalogue

Generated by scripts/catalogue.py from the layer definitions, scripts/split.manifest, the Language support data (coverage.json) and docs/platforms.json. Edit those inputs and regenerate; scripts/catalogue.py --check refuses a stale copy.

Measured on 2026-11-23. Each language row gives the module's state on Language support, linked to its entry there, then the client: the facade's resolve accessors, or for JavaScript the generated service clients a binding from [Machine.resolveService](https://openabstractions.github.io/reference.html#concept-facade.machine-client) wraps. Checked means that language's client or record types passed a recorded check against the running OA runtime; available means a client exists and no current check is recorded. Test connection marks a checked state whose check passed only over the Go IPC connection, the test-only pipe connector or a connection the check did not record. Ship on a checked state on your platform.
