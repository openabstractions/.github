# Layer catalogue

Generated by scripts/catalogue.py from the layer definitions, scripts/split.manifest, docs/results/MATRIX.txt and docs/platforms.json. Edit those inputs and regenerate; scripts/catalogue.py --check refuses a stale copy.

Measured on 2026-10-20. Each language row gives the verdict of the legacy whole-layer grid for the layer's own implementation (— is none), then the client: the facade's resolve accessors, or for JavaScript the generated service clients a binding from Machine.resolveService wraps. UNPROVEN means the grid found nothing to check: usually source for that layer and language exists with no test files the gate names, so no run happened and no verdict, pass or fail, was recorded. For an adopter, an UNPROVEN cell means the binding compiles and its behaviour is unverified on that platform; ship on a PASS cell.

| JavaScript | matrix UNPROVEN; client LeasesClient (abstraction.resource/leases@1), TableClient (abstraction.resource/table@1) |

**Platforms:** the runtime's (Runtime platforms above); supported: windows-user, windows-machine, linux-systemd-user, macos; supported without background services: linux-no-user-manager; unsupported: android-termux.
